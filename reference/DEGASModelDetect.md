# Auto-select Model for DEGAS

Automatically select the DEGAS model based on single-cell labels and
bulk-level phenotype information.

## Usage

``` r
DEGASModelDetect(sc_pheno_colname, bulk_pheno, call = rlang::caller_env())
```

# Generate roxygen lines for the `@param` of [`MethodParamSet()`](https://wanglabcsu.github.io/sigbridger/reference/MethodParamSet.md)

One `@param` tag per registered method, in registry order.

One markdown bullet per registered method, in registry order.

## Usage

``` r
GenerateRoxy.MethodParamSet()

GenerateRoxy.Screen.screen_method()
```

## Value

[`character()`](https://rdrr.io/r/base/character.html) of roxygen lines,
one per tag.

[`character()`](https://rdrr.io/r/base/character.html) of roxygen lines
defining the complete `@param screen_method` tag.

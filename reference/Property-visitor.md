# Retrieve a property from SigBridgeR object

Retrieve a property from SigBridgeR object

## Usage

``` r
# S3 method for class '`SigBridgeR::SigBridgeRBase`'
object$name

# S3 method for class '`SigBridgeR::SigBridgeRBase`'
object[[name]]
```

## Arguments

- object:

  An object inheriting from SigBridgeRBase

- name:

  The name of the parameter as a character. Partial matching is not
  performed.
